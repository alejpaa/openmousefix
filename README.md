# OpenMouseFix

App de código abierto para macOS que mejora el uso de ratones normales:

- Scroll suave con aceleración para la rueda del ratón
- Dirección de scroll independiente para el ratón y el trackpad
- Botones laterales: clic (Atrás/Adelante…) y gestos de mantener + arrastrar (cambiar de escritorio, Mission Control, App Exposé…)
